# Security

> Last verified 2026-11-04 against `5276584`.

## Reporting

Report a suspected vulnerability privately to the repository owner (Ian, GitHub
`cre3tr`), for example through the repository's "Security" tab if private
reporting is enabled, or by contacting the owner directly. Please do not open a
public issue for it.

## Supported versions

Only the latest commit on `main`, which is what is deployed at
<https://sentiscop3.vercel.app>. There are no tagged releases.

The internal security state of this project is tracked privately by the owner.
